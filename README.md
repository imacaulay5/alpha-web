
# Alpha

Alpha is an AI-assisted accounting workspace for people who want clear financial next steps without needing to think like an accountant.

The production roadmap is now focused on a V1 loop:

- Track money in through invoices and payments.
- Track money out through bills and expenses.
- Keep clients, projects, and categories organized.
- Surface dashboard next steps that can later be powered by AI.
- Prepare clean records for reports and tax exports.

Advanced ERP-style modules such as payroll, inventory, team approvals, purchase orders, and full ledger accounting remain in the codebase for later phases, but they are not the primary production surface.

The original Figma project is available at https://www.figma.com/design/OdNWnKLo6NSmp5qzVaOKSR/ERP-System-for-SMEs.

## Running the code

Run `npm i` to install the dependencies.

Run `npm run dev` to start the development server.
